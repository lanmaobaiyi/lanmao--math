# 模块化数学建模运行规范

这是可直接阅读、裁剪和复用的数学建模知识库。内容覆盖审题、条件核对、路线设计、数学推导、本题计算、数学核验、图表表达、答案交接和结果证据。

## 使用顺序

1. 先读 数模运行基本规范/启动.md，确定阅读路径。
2. 完整任务先读 数模运行基本规范/知识库/通用/模块化总控与调用规范.md。
3. 按需要读取 统一约定.md、数学推演.md、题型协议.md、KNOWLEDGE_BASE.md、图表规范.md 和题型专页。
4. 需要记录任务成果时，按 数模运行基本规范/模板/README.md 选择相应模板。

## 内容结构

- 数模运行基本规范/知识库/通用/ 保存核心运行规则、数学推演、证据、图表和复核原则。
- 数模运行基本规范/知识库/题型/ 保存带适用前提的参考模型。
- 数模运行基本规范/模板/ 保存问题约定、来源、核验、稳健性和视觉审阅等记录格式。
- 数模运行基本规范/启动.md 提供快速导航。

## 发布边界

本包只包含现行知识库、必要导航和通用记录模板。具体题包、聊天历史、个人本机路径、历史案例、维护方案和运行环境配置不属于本包。知识库中的题型公式是带适用条件的参考内容，不能替代当前题目的建模、计算或核验。

本包不要求安装软件或建立额外平台。使用时应依据实际题目、授权范围、资料边界、预算和停止条件开展工作，并如实区分已完成、未执行、不适用和待复核事项。

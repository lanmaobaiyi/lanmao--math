# 建模记录模板

这些是开展本题工作时按需采用的记录格式，不是需要启动的软件包。阅读规范不意味着复制整目录或创建所有文件；只读任务可在对话中使用相同内容结构。

本目录保存模板原件，不是具体题目的输出目录。采用模板内容时，按[运行主规范第0.1节](../知识库/通用/模块化总控与调用规范.md)保存到本题成果位置，已有明确位置直接沿用；不把题目代码、数据或结果写回模板原件所在目录，也不为使用模板另设确认步骤。

**迁出时处理链接**：只取适用记录内容，不将模板目录原样复制成题包。“怎样填写、去哪里读规则”等规范操作导航不是题目证据，可省去或改为不依赖模板原目录的文字说明；真正支撑本题的来源、方法与核验引用必须保留，不能为消除坏链接而删除。确需保留的链接按最终使用位置重新定位：包内成果优先采用正确相对关系，约定外部来源保留真实可访问地址。本机绝对路径只解决本机定位，不证明跨机可用；不以建立假知识库目录或复制整库修复导航。迁出后仍按M08核语义、引用及必要依赖。

| 需要记录什么 | 模板／说明 | 使用时机 |
|---|---|---|
| 本题要求、范围及设计 | [问题约定](problem_contract.md) | 审题、方案与模型交接 |
| 原题到子项的覆盖 | [题面覆盖说明](题面覆盖填写说明.md) | 帮助填写问题约定，不另建需求副本 |
| 来源及成果位置 | [证据索引](evidence_manifest.md) | 文件较多或需要复现时 |
| 结论与证据关系 | [关键结论](claim_registry.md) | 答案较多、需要单独索引时 |
| 实际核验 | [验证记录](verification_report.md) | 推导审阅或计算核验后 |
| 扰动与不确定性 | [稳健性记录](robustness_report.md) | 确实开展适用分析时 |
| 图表实际审阅 | [看图记录](视觉验收说明.md) | 交付图片前 |

按需使用的组织说明还包括[共享目录说明](共享/README.md)、[探针与验证支撑](探针/README.md)和[原始输入只读说明](input/只读说明.md)。这些页面只说明题目成果的组织和记录方式，不要求创建同名目录，也不增加新的验收状态。

不要求固定JSON、机器字段或软件验收状态。问题约定记录“需要什么”，模型说明记录“如何得到”，结果保存实际答案，验证记录说明“依据是什么”；其他表只引用这些来源，不重复维护答案数值。

成套文件按[运行主规范M08](../知识库/通用/模块化总控与调用规范.md#m08-逐项答案与成果整理)的目录与选集规则落实：默认按实际问题编号和主题分目录，每问有明确答案入口，适用的代码、图片、结果分别归入`code/`、`figures/`、`results/`；共享材料按需单列。用户明确的结构优先，不能以“已有组织”跳过整改。纯解析不建空代码目录，无图不建空图目录，但已有成果须分类；过程留存不混入正式选集，原件仍只读。完成前查看实际落盘目录及答案语义，不只提供目录方案。

规范维护记录不混入题目成果。原始资料只读，不自动覆盖已有目录或用户文件。执行流程、模块职责、题型门槛和证据定义均以[知识导航](../知识库/README.md)指向的唯一正文为准。

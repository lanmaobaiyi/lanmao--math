# 本题数学核验记录

纯推导审阅和计算核验均可用，不要求专用验证软件。实际执行、检查结果与数学结论分开。模板空白不代表通过，也不能据此断言未执行；先核已有证据，无法确认时记“未知／待核”。有效既有检查可引用，状态和复用口径按[结果与证据](../知识库/通用/KNOWLEDGE_BASE.md)第1节。

# 探针与验证支撑

本题确需计算时，可在本题成果位置保留数据初检、探索、独立核验和参数扰动的脚本与输出，不写入规范库的模板源目录；已有合理目录直接沿用，不强制名为“探针”的目录，不为模板创建空脚手架。每份正式结果说明生成入口。执行服从当前授权，规范整理不因此启动计算或测试。

被正式结论引用的核验、实验、配置与结果是复现支撑，应保留并按交付约定提供；不能为精简删除依赖。未被引用的临时探索可不列入交付，不自动删除。具体来源与复现口径见[结果与证据](../../知识库/通用/KNOWLEDGE_BASE.md)。

声称计算独立复核时，从原始输入重新建立检查，允许读取最终解或预测结果作比较，不能复用主模型中间缓存或主核心来冒充独立重算；共享 I/O 辅助须说明范围。普通错误定位、逐步审阅或实现诊断可以检查主过程及中间结果，但不能因此宣称获得第二条独立证据。具体边界按[结果与证据第3节](../../知识库/通用/KNOWLEDGE_BASE.md)，函数名相同不能单独证明同源。

# 题面到必答子项的覆盖说明

本页帮助填写[问题约定](problem_contract.md)中的需求表，不维护另一份需求台账，不要求机器字段。

1. 读完整原题与附件说明，从每句要求抽取必答对象；一个问号可能包含推导、计算、比较、解释等多个子项。
2. 给子项可稳定引用的标识，记录真实原文和定位；不补写页码、不以自动改写冒充逐字引用。
3. 明确什么答案才算回答本项：对象、单位、范围、条件和应有证据。
4. 从原题重新寻找表外遗漏，再从拟交答案反查是否答非所问；只核已登记标识不能发现漏登记。
5. 区分原题必答、用户本次选中项和可选增强，未选项保留可见，不把缩小范围说成全题完成。

PDF、图片和公式抽取不清楚时核原件，保留关键差异。表格的单位、行列对应及图示是否按比例都可能影响题意；不能仅凭抽取文本格式正确认定语义完整。

审题者、实际阅读范围和未解决问题如实说明。具备授权的第二审查者应从原始资料重建关键需求再对照，不只复述主作者清单。同一执行者重读仍是自审，规则见[总控A01](../知识库/通用/模块化总控与调用规范.md)。

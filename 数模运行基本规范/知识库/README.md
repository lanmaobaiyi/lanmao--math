# 数学建模知识库目录

本目录是模块化数学建模运行规范的核心知识库。规则按主题分布，但每类规则只有一个完整维护位置。先读[统一约定](通用/统一约定.md)了解术语、状态词和结论强度，再按任务选择文档。

## 题型参考

[题型目录](题型/README.md)列出当前专页。专页必须先核对适用前提，参考公式和示例不能替代当前题目的建模、计算或核验。

## 使用边界

知识库只维护通用规则和带适用条件的参考内容。具体题目的参数、数据、代码、结果、图片和失败记录留在题目成果位置。模板提供记录格式，经验提供案例提示，二者都不建立第二套完成标准或状态系统。

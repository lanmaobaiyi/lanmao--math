# 通用经验手册

经验记录错误模式，不把某道题的公式、参数或结论当作普遍规则。执行顺序见[运行主规范](模块化总控与调用规范.md)第0.3节。

## 从问题开始

先明确要回答什么、使用什么数据、指标代表什么，再选算法。优化先定义合法解，预测先确定预测时点和信息边界，统计先确定抽样与推断对象，评价先解释指标方向与权重，机理模型先明确单位、状态和初边值。

先做便宜而能发现错误的检查：小实例、端点、单位、空数据、零方差、错误时间顺序、极端参数和已知解析解。模型更复杂不代表结论更可靠。一个足以回答题意且通过验证的简单方法可以作为正式模型。

## 错误与防线

| 错误表征 | 常见原因 | 防线 |
|---|---|---|
| 同一输入给出不同口径的数字 | 契约或数据版本漂移 | 记录字段定义、输入身份和契约版本 |
| 主结果与验证器一起出错 | 重用了核心计算、缓存或待核验的读取/转换前提 | 按[结果与证据第3节](KNOWLEDGE_BASE.md#3-独立性和重复证据)辨明共享边界；例如共用同一错误日期解析不能独立验证该解析 |
| 预测准确得异常 | 未来信息、全量归一化、重复个体泄漏 | 划分后拟合预处理，按时间或组隔离 |
| 排名对微小变化剧烈波动 | 权重或归一化敏感 | 登记扰动范围并测排序稳定性 |
| 只展示最好的一次随机结果 | 选择性报告 | 保留种子计划、全部重复和失败情况 |
| 把未显著解释成无效应 | 忽略效应量、样本量和区间 | 同时报估计、置信区间与检验前提 |
| 数值解平滑但错误 | 单位、守恒或离散误差 | 解析/已知基准及步长、网格收敛 |
| 老机器能跑，新机器失败 | 环境依赖未记录 | 相对启动入口、依赖版本和最小检查 |
| 审阅找不到文件或误用过期结果 | 副本或路径漂移 | 明确正式来源位置，核对输入、模型与成果版本；仍有效的既有证据注明复用，不要求仅为换会话重跑 |
| 图与数字不同 | 旧图、手填数据、状态混用 | 当前结果出图，登记来源并核对清单 |
| 可读取的日期或重复格点被当作事件标签或独立样本 | 对象身份与实际用途混淆 | 回[主规范M02](模块化总控与调用规范.md)核含义和对应；解析成功不能补齐语义 |
| 无真实标签却把情景范围称为已校准事件概率区间 | 条件研究越界为现实实证 | 回[题型协议](题型协议.md)核主张；有依据的条件研究仍可继续，不冒充已满足实证要求 |
| 固定有效比被当作固定各物理参数，代表位置被当作全区 | 上游量的身份或适用域在传递中丢失 | 回[主规范第4节](模块化总控与调用规范.md)，使用所传对象及其限制，不仅比较数值是否相等 |
| 总量或末速度一致便声称时间、分支和逐点身份全部核验 | 用一个指标代替未覆盖对象 | 按[题型协议](题型协议.md)限定主张，执行对象与数量按[结果与证据第1节](KNOWLEDGE_BASE.md#1-结论执行与检查分开)记录 |
| 精简后必要解释缺失，却因CSV与旧稿仍在而称答案完整 | 文件保留被当作语义保留 | 回[结果与证据第5节](KNOWLEDGE_BASE.md#5-结果变更与交付)从必答内容核当前正式答案，不要求逐字保留旧稿 |

## 结论应有边界

可行性、最优性、泛化、因果、显著性、收敛与稳健性是不同主张，不能互相替代。固定种子重跑成功只能支持相应复现记录；残差不正态不自动否定整个模型，应看所用估计和推断方法的前提。没有执行的试验写 NOT_RUN，真实不适用的项目写理由。

上游数据、边界或选定模型变化后，按[结果与证据](KNOWLEDGE_BASE.md)沿实际依赖识别受影响成果；未受影响且仍有效的证据可以复用。需要重算不等于获准重算：当前禁算或预算不足时，将受影响结论标为待复核，不作为当前已验证答案；仅继续不依赖它的授权工作。必要复算按主规范第0.2、0.5节取得相应授权后进行。失败记录必须保留，不从旧报告中摘取通过结论拼成新答案。

停止条件见[运行主规范](模块化总控与调用规范.md)第0.5节，改进和比较方法见[改进阶梯](改进阶梯.md)。本页是常见错误提示，不要求每次全表重查；按实际风险及总控A01使用。

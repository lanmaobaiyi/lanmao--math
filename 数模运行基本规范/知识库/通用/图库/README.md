# 按数学表达目的选图

本页是图型参考，不提供或调用旧绘图软件。通用要求见[图表规范](../图表规范.md)，按题意选择，不机械每类各画一张。

| 要表达的关系 | 可选图型 | 注意 |
|---|---|---|
| 时间或有序变化 | 折线、阶梯 | 时间间隔、缺测、事件边界和外推范围 |
| 类别/方案比较 | 条形、点图 | 同单位同口径，长标签可横向排列 |
| 分布和不确定性 | 直方、箱线、经验分布、区间图 | 分箱、样本数、异常点及区间含义 |
| 变量关系 | 散点 | 趋势拟合须有依据，不暗示因果 |
| 参数敏感性 | 有符号变化图、曲线、热图 | 两端变化可同正或同负，不强改符号；局部不称全局 |
| 决策权衡 | 目标空间点图、可行域或帕累托图 | 支配关系、目标方向与搜索覆盖范围 |
| 解析关系或结构 | 函数图、网络或示意图 | 定义域、比例及示意性质；不伪造观测 |
| 空间几何与标量场 | 三维曲面、等值面、切片、体渲染 | 字段位置、尺度和遮挡；现有表达不足以支持所需比较时补投影、剖面或同源表 |
| 方向与输运关系 | 向量图、流线、实际计算的轨迹 | 分量/模长、种子和积分范围；瞬时流线与时变轨迹不混同 |
| 时变仿真及情景对照 | 同视角分时图、空间图与同源曲线组合 | 时刻与情景对齐、可比较色标；动画按需而非默认 |

图的选型理由和来源写进本题已有记录，不另建图库验收清单。空间、场和时变结果的几何—字段—显示映射按[图表规范](../图表规范.md#空间与仿真表达)核对，不以立体效果替代证据。

## 可借鉴的真实图组与代码

以下仅提供表达与复现方法的来源，不是固定图数、配色或软件要求，不下载执行其中代码作为默认步骤：

- [Journal of Scientific Computing，2026，DOI 10.1007/s10915-026-03253-4，图1](https://link.springer.com/article/10.1007/s10915-026-03253-4)：将二维/三维几何、网格和场分布组成三联图，短子图标识与长解释分开。可借鉴空间对象与场的对应，不直接照搬彩虹配色或把未见色条当作定量图可省色标的依据。
- [Journal of Scientific Computing，2025，DOI 10.1007/s10915-025-02810-7，图1及图7](https://link.springer.com/article/10.1007/s10915-025-02810-7)：图1以并排对数曲线、符号/线型和参考斜率比较收敛；图7按时间组织相场与速度的多面板。可借鉴“现象/过程与定量核验互补”，不由此规定每问必须包含相同角色或张数。出版方HTML图片可供观察布局，不用于推定印刷字号、线宽或本题最终尺寸已验收。
- [SimPEG作者的三维电磁建模研究仓库](https://github.com/simpeg-research/oldenburg-2018-AEM)：提供关联论文图的notebook与Python代码，体现真实场量、模型和图形的连接。使用前仍核输入、依赖、路径及版本；公开代码不等于本机已验证可运行，不照搬其机器路径或导出设置。
- [CUQI作者书籍的逆问题示例](https://cuqi-dtu.github.io/CUQI-Book/intro-example-short/)及[源码仓库](https://github.com/CUQI-DTU/CUQI-Book)：从明确模型和模拟数据到点估计、后验及相应绘图，可参考分析对象驱动图组的方法；不能把其先验、随机模拟或不确定性图强加给非统计任务。

官方图稿要求与当前题目风格选择的关系见[图表规范第5节](../图表规范.md#5-外部依据的使用边界)。阅读外部示例不授权安装、联网传输原题资料或复制他人的图冒充本题结果。

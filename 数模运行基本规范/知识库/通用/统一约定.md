# 模块化数学建模统一约定

本页统一解释术语、状态词和数学书写口径。运行步骤、模块职责和返工方向仍以[模块化数学建模运行规范](模块化总控与调用规范.md)为准，结果证据以[结果与证据规范](KNOWLEDGE_BASE.md)为准。本页用于减少跨文档寻找定义的成本，不另建一套流程。

## 1. 规范用语

| 用语 | 含义 |
|---|---|
| 必须、禁止 | 适用于当前任务且不能由执行者自行省略或替换的要求 |
| 应、不得 | 默认要求。确有不适用情形时，说明理由、影响和替代路径 |
| 可、按需 | 由题意、证据和授权决定，不构成固定产物或固定步骤 |
| 当前任务 | 用户本轮明确的对象、范围、允许操作、交付目标和停止条件 |
| 原始资料 | 题面、附件、观测和用户明确指定的来源。原始资料保持只读 |
| 派生成果 | 抽取、清洗、模型、代码、结果、图表和答案等由任务产生的内容 |
| 权威位置 | 当前任务中被选定、可定位且用于交接的答案、模型或结果来源 |

模块表示一组工作职责，不要求建立同名文件、程序或独立执行单元。工作单元由“问题、必答子项、本次目标”组成。职责可以合并，但合并后仍需保留相应的条件、推导、证据和答案。

## 2. 数学对象的身份

建模过程中区分以下对象，交接时保留其身份和适用范围：

1. **题面事实**。原题明确给出的对象、数值、关系、限制和交付要求。
2. **模型假设**。为了闭合关系或选择方法而加入的条件，必须说明来源、范围和可能影响。
3. **推导关系**。由事实、假设、定义或已证明性质得到的等式、不等式、集合、概率关系或命题。
4. **情景设定**。用于条件研究或比较的设定，不能改写成题面事实或现实观测。
5. **计算结果**。在具体输入、模型和方法下获得的数值、方案、轨迹或状态。
6. **核验依据**。用于判断推导、实现、结果或主张的独立判据、回代、界、误差、观测或审阅。

数值相同不代表对象相同。不同来源、不同时间尺度、不同样本、不同总体、不同参数身份或不同适用条件不能因为打印值相等而直接合并。

## 3. 状态词和结论强度

### 3.1 执行状态

| 状态 | 使用条件 |
|---|---|
| 已核对且满足标准 | 已实际执行相应检查，观察结果满足预先约定的标准，并注明覆盖范围 |
| 发现问题 | 检查已经执行且发现违反条件、实现错误、证据不足或表达失真 |
| 未执行 | 本次没有开展该项检查、计算或复现 |
| 待核 | 需要的来源、状态、版本或结果尚不能确认 |
| 不适用 | 依据当前任务的数学对象和主张，该项检查没有适用含义，并说明理由 |

缺资料、禁算、工具失败、预算不足和没有取得输出均保留为未执行、待核或失败事实，不能改写成不适用。文件存在、程序结束或求解器返回成功也不能单独产生“已核对且满足标准”。

### 3.2 结论强度

结论使用能够被当前证据支持的最小强度。常见层次如下：

| 结论 | 至少需要说明 |
|---|---|
| 条件性关系或推导 | 前提、定义域、变形条件和适用范围 |
| 可行方案 | 原题约束、变量域、单位和逐条回代结果 |
| 最优方案 | 同一问题的最优性证明或有效界，以及容差口径 |
| 预测或总体推断 | 信息边界、样本结构、方法前提和相应评估依据 |
| 稳健或稳定结论 | 扰动对象、范围、指标和能够排除的变化 |
| 因果结论 | 干预对象、识别依据、对照条件和关键假设 |

“条件下成立”“当前方案可行”“固定背景下最优”“尚未证最优”和“现实效果已验证”属于不同陈述，不能用较弱证据替换较强结论。

## 4. 统一数学书写口径

- 集合、索引、变量域、单位、样本身份和时间尺度在每个模型中首次使用时定义。
- 区间端点按题面或模型明确采用开区间、闭区间或半开区间。端点相接是否冲突必须写明。
- 时间窗、重复计划、事件标签和观测样本分别命名。周期展开不能替代有限索引检查。
- 求和、平均、分母、概率和误差对应的总体或样本必须明确。不同分母的数值不能直接比较。
- 变换、聚合、降维、舍入和取整须说明逆变换、信息损失及对约束和结论的影响。
- 解析、浮点、随机和仿真结果分别说明精度、容差、种子、重复或情景口径。打印成整数不自动表示目标只能取整数。

## 5. 文件、来源和交接

正式结果只从当前有效的权威位置读取。跨问、制图和答案交接时保留来源版本、对象身份、单位、样本、条件、误差或不确定性，以及结果由求解、核验、重绘还是固定方案复现得到。

来源正在写入、解析失败或身份不一致时暂停接收。旧结果只有在题意、输入、模型、条件和核验用途仍适用时才能复用。路径、文件名、哈希或修改时间只能帮助识别来源，不能单独证明数学正确、可运行或证据仍有效。

## 6. 使用边界

本页适用于通用规范、题型专页、模板和具体题目成果的术语解释。题型专页可以补充本题型的符号和边界，但不能覆盖本页的状态含义、证据强度或原始资料边界。发现冲突时回到当前题意、主规范和结果证据判断，不新增第三套定义。

# 按数学任务选择证据

本页维护题型所需的数学证据，不依赖机器注册表。按必答子项、实际模型和拟提出的结论选用；一问含多个组件时分别核验，再检查联合关系。解析证明不是单独题型，各领域均可有解析和计算路线。

## 题型与强结论

| 数学任务 | 基本核对 | 强结论所需证据／常见误用 |
|---|---|---|
| 优化、资源分配 | 可行域、逐条约束、目标独立重算、单位和方向 | 全局最优需证明或有效界；搜索失败不是不可行证明；局部收敛不是全局最优 |
| 排班与调度 | 优化要求，加时间窗、端点、互斥、资源负荷与重复语义 | 排列合法不等于时间/容量合法；启发式无冲突不证明最小成本 |
| 预测、回归 | 预测时点、划分、防泄漏、误差、适用简单基线 | 泛化需合理留出/外部证据；训练拟合和模拟演示不能替代 |
| 综合评价 | 指标方向、归一化、权重来源、得分排序复算、冗余计权 | 稳定排名需适用扰动证据；AHP一致性只针对判断矩阵，不证明客观权重正确 |
| 统计推断 | 总体、抽样与群组结构、估计量、方法前提、效应量及不确定性 | 多重比较需考虑选择过程；不显著不证明无效应；相关不推出因果 |
| 图论与网络 | 节点/边/方向/权重、路径或流合法性、原始图核对 | 最短、最大、不可达等需相应算法条件和证据，不以未找到当不存在 |
| 机理、微分方程 | 状态、单位、初边界、方程闭合、可识别性、数值误差 | 守恒仅在方程具备时检查；拟合好不证明参数唯一或机理真实 |
| 随机仿真 | 随机机制、情景来源、重复/相关性、估计误差和收敛依据 | 预热按过程性质决定；均值精度不等于单次稳定，仿真不自动证明现实预测 |
| 分类与监督学习 | 标签来源、划分、防泄漏、类别不平衡、适合的基线与指标 | 准确率不一定反映关键类别；概率主张需相应校准等证据 |
| 聚类与无监督 | 预处理、距离、尺度、有效性、稳定性、实际解释 | 内部指标高不证明存在真实类别；外部标签按实际可得性使用 |

## 选择检查，不套固定菜单

优化界须说明方向和适用范围：最小化问题的可行解值给上界，最大化问题的可行解值给下界；相对间隙还须说明定义、分母及容差，负值或零值不能直接套含糊公式。不可行或无界结论也要有对应证据，不从一次失败推出。

有界不等于已经证明最优。对最小化问题，若当前可行解值为U，另有同一问题的有效下界L，则最优值位于[L,U]；有效界精确相合可据此得到精确最优性，按预先约定容差闭合时应报告该容差下的最优性及剩余间隙。原始界未相合时，可用已证明的目标取值结构强化界；只有据此排除了所有更优目标值，或另有适用证明，才能称精确最优，否则仍保留差距。不同约束、目标口径或条件下的界不能直接拼接。最大化问题相应交换可行解界与另一侧界的角色，不把启发式最好一次当另一侧界。

例如已证明目标值只能取整数时，最小化问题的有效下界L可加强为⌈L⌉；若U是已核验可行解的整数目标值且⌈L⌉=U，即使原始L不等于U，也能证明U最优。仅决策变量取整数、目标显示为整数或打印小数接近U，都不能代替目标取值结构及界有效性的证明。此处是数学判别说明，不引入默认容差或新增计算要求。

同时区分可行域为空、目标无界与有限确界未取到。例如在`x>0`上最小化x，可行域非空、下确界为0，但任一可行x都有更小的可行值x/2，因此没有最小点；不能把它报告为不可行或目标无界。若约束改为`x≥0`，0才是取得最小值的可行解。具体结论须对应原变量域，不把极限值当作已获得的可行方案。

先写“要支持的结论—可能出错的条件—判别办法—可接受标准”，再实施。阈值、容差、比较划分和停止条件应在看结果前确定；事后调整须披露，不能换名称清除选择影响。

无计算的证明重在前提、推导、适用域和反例，不要求数值种子或运行基线。精确求值已有独立真值时，可直接核对真值，不强制另跑无信息增量的比较算法；声称方法改善或预测能力时不能省掉适用对照。

稳健性是对相关扰动与结论变化的判断，不要求每题机械调所有参数。固定且精确的题给条件、纯定理等场合说明相应数值扰动为何不适用；必要正确性检查仍保留。缺观测、未授权、未执行、失败不能归入不适用。

敏感性或稳健性可以由适用的解析推导（如导数、误差界、单调性证明）、数值扰动或统计证据支持，须说明对象、尺度、扰动域和判别标准。局部导数不能直接推广成全域稳定，理论误差界不能替代现实观测验证。无数值试验不等于无证据，有推导也不等于所有稳健性要求均已满足。

## 把验证计划落到判别动作

从当前结论最可能失效的位置选择有判别力的检查，不照表全做，也不要求每项有独立报告。计划写清对象、方法前提、预定标准和失败后的结论影响；执行受当前授权限制，实际记录沿用[核验模板](../../模板/verification_report.md)或已有成果。执行方式、案例/检查项/尝试数量及结果口径统一按[结果与证据第1节](KNOWLEDGE_BASE.md#1-结论执行与检查分开)，本页只判断数学判据、覆盖限制与结论强度；复核分工、独立性和重复检查仍按总控及结果与证据规范。

| 所需判断 | 怎样检查 | 能支持什么、不能替代什么 |
|---|---|---|
| 解析关系或命题是否成立 | 从定义和前提出发逐步核对关键变形，检查分支、边界及反例；证明存在/唯一/最优时分别给相应论证 | 能支持论证覆盖域内的结论；几个代入值不证明一般命题，条件命题的证明不等于现实满足其前提 |
| 候选解是否合法、目标算得对不对 | 由原始条件重建所需约束并回代，按原定义重算目标/指标；逐条定位违反位置、大小和单位 | 支持相应可行性和指标值；不自动支持最优、现实有效性或其他未检查约束 |
| 公式到计算是否译错 | 用独立解析值、可手工核对情形或适用恒等关系比较，检查索引、尺度和输入输出映射 | 支持被检查的计算关系；不能把主输出作为预期真值，也不能从小情形外推所有实例 |
| 方程残差或迭代停止是否足够 | 明确残差定义、尺度及容差；要主张解误差小，还需误差界、条件性分析或其他适用依据 | 小残差/相邻迭代变化小不自动等于解接近真值；达到迭代上限只是停止事实 |
| 离散化或数值近似是否足够 | 在授权内改变步长、网格或精度并比较同一目标量，结合方法适用条件、基准或误差估计 | 可形成收敛/近似误差证据；两次接近不独自证明收敛，更不验证现实机理 |
| 预测是否能泛化到目标范围 | 核信息可得时点与样本结构，在适用留出或外部资料上按预定指标评估，并保留总体/群组差异及不确定性 | 支持所覆盖使用范围的预测主张；训练拟合、调参用验证集和未经依据的合成数据不能替代最终评估 |
| 样本结论能否用于总体推断 | 核抽样/观测机制、估计量、相关结构、模型前提及选择过程，据此解释效应、区间或检验 | 支持相应前提下的推断；不强制训练/测试划分，也不以留出误差代替抽样代表性、推断前提或因果依据 |
| 结果能否作因果解释（仅涉及该主张时） | 明确干预或变化、对照情形、结果与适用对象，核查识别该效应的设计/推导依据及关键假设，区分观测差异与模型内推演；对照情形不等于必须另设实验对照组 | 仅支持相应依据和假设覆盖的因果结论；相关、拟合好、预测准确或单纯前后差异不单独确立因果 |
| 随机估计是否达到所需精度 | 对准正式估计量，按实际依赖结构处理重复与区间，并核对精度/收敛依据及失败情况 | 均值、分位数或风险指标各需自身依据；固定种子、最优一次或成功运行子集不能代表整个随机过程 |

符号反例：对方程`εx=ε`且`ε>0`，真解为1；候选`x=0`的绝对残差为ε，解误差却为1。ε可以很小，所以只套固定绝对残差阈值可能错误接受该解。应结合尺度及能把残差联系到解误差的依据，而不是统一换一个更小常数。此为代数说明，不是已执行数值试验，也不要求每题都建立同一种误差界。

因果依据不足时，保留可支持的关联、预测或条件性模型结论，并说明未解决的因果要求及最小补证需求，返回相应条件或路线工作；不通过改称相关性分析就把原题的因果必答项标成完成。不涉及因果主张的任务不增加这项工作，也不强制指定某种研究设计或另建报告。

## 样本与随机估计

先区分仅描述给定对象、由样本推断总体和预测新对象。同一种回归、聚类或变换也可能服务不同目的，证据随实际主张选择。仅描述声明范围内的对象时，可以使用该分析范围的资料，不为形式完整而强拆训练/测试集；但不能据此声称泛化。总体推断须核抽样与方法前提，不把划分数据当作通用替代。涉及泛化评估或既定训练/验证划分时，预处理的拟合、特征选择和调参均遵守相应信息边界；交叉验证时也在各训练部分内完成，不先用全部评估样本拟合再划分。

样本身份、总体、单位和分母跟随指标；不能在模型、比较和图表之间悄悄换样本或排序。时序预测按信息可得时间划分，重复个体/群组保留合理隔离，独立样本按适合方案处理，不一律强制时间划分。

随机答案若是均值、分位数、概率或风险指标，正式结果就应对应该估计量及全部约定样本，不用首个种子或最好一次替代。说明样本相关性；重复不足只能给受限结论。区间含义、置信度和计算前提要明确。

出现失败或无效输出时，按[结果与证据第1节](KNOWLEDGE_BASE.md#1-结论执行与检查分开)保留实际执行与覆盖记录；不能把失败默填为零或无声剔除后仍声称代表原估计对象。只对成功运行汇总时明确这是条件于成功的结果及其覆盖限制，不能直接代替原要求；必要补证或变更设计按当前授权处理。重抽样或联合模拟须保留原任务相关结构，增加随机次数不能补救错误的抽样对象或来源假设。

## 解释与使用

图表按数学表达需要选用，不要求每种题型必须有固定数量或固定角色的图。残差或预测误差图须有相互对应的观测与拟合/预测值，标明误差定义及样本内、留出或外部评估性质；样本内残差可用于相应诊断，但不能冒充样本外预测证据。没有对应观测不能编造误差图，没有不确定性依据不能画假置信带；无必要图形时直接解释结论。

记录方式见[结果与证据](KNOWLEDGE_BASE.md)，复核分工见[总控A01](模块化总控与调用规范.md)。专用参考模型见[题型库](../题型/README.md)，只在实际适用时读取。

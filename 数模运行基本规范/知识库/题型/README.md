# 题型数学参考

本目录保存供建模使用的数学对象、边界与证据要点，不是软件模块集合，不要求每个题型有测试程序。

先按原题识别实际数学任务，再读[通用题型协议](../通用/题型协议.md)及适用专页。一个问题可以组合多个领域，不按已有目录强行归类。

| 专页 | 用途 |
|---|---|
| [时频窗口](时频窗口/README.md)与[数学规格](时频窗口/数学规格.md) | 有限重复窗口、周期与端点、冲突关系 |
| [选址分配](选址分配/README.md)与[数学规格](选址分配/数学规格.md) | 开放设施、分配需求、成本口径与容量约束 |

没有专页不阻断建模：先依据原题、通用数学规则和必要的可靠资料开展本题分析。只有确有可复用知识且维护获准时才增加简短参考；不为每道题自动建新模块。

专页统一采用“适用前提—数学对象—关系或模型—可支持结论—不能推出的结论—核验动作”的组织方式。内容不预设题目参数，不复制软件接口，不要求新建测试目录。跨题型组合通过总控的数学交接处理，共享规则引用通用层，不各维护一份。

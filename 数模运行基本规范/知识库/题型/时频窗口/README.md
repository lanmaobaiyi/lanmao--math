# 题型：时频窗口

适用于有限次重复占用、频段与时间窗、间隔与周期、冲突判定等结构；具体区间口径、合法动作和资源边界须由当前原题确定。

## 阅读与使用

阅读[数学规格](数学规格.md)，核对有限窗口、周期、冲突判别与边界；不调用旧参考程序或测试。

采用前核对数学前提。题目特有的反例、计算与核验记录保存在该题，实际计算受当前授权限制，不把赛题历史写回通用规范。

## 必查问题

- 题给的是相邻起点间隔，还是前次结束到下次开始的间隔？后者才有 P=L+g。
- 端点相接是否算冲突？半开与闭区间不能混用。
- 重复次数是否有限？无限相位近似须有等价性依据。
- 调整、撤销、最小间隔、资源终点和动作互斥是否为当前题目的真实条件？
- 可行解与最优性是否区分？没有证明或有效界不能声明最优。
- 首次窗口、总跨度、记录数与实际改变数是否分别定义？

通用规则以[运行主规范](../../通用/模块化总控与调用规范.md)和[铁律](../../通用/铁律.md)为准。适用检查不足时保持待审或未完成，不套用其他题目的结果。

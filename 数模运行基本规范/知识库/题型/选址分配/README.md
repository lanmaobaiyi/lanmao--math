# 题型：选址—分配

适用于从候选点选择设施、分配需求，并受容量、预算或服务条件限制的问题。目标、距离口径、成本时间尺度和是否允许未满足需求均从当前题目确定。

## 阅读与使用

阅读[数学规格](数学规格.md)中的参考变量、目标、约束与条件；不调用旧参考程序或测试。

## 必查问题

- 先检查总容量及开放数限制下的容量上界；必要条件满足不代表问题一定可行。
- 实际纳入目标的建设、出行、缺额等成本须统一单位和时间尺度；不为凑齐成本项引入题目未要求的费用，寿命、年运营天数、往返口径及折现规则不能取无依据默认值。
- 设施关闭时不得承接分配；允许未满足需求时，明确缺额如何计量及其在约束、目标或结果中的处理方式。仅在采用惩罚模型时定义惩罚项及依据，不自动增加惩罚系数；缺额可由已有量明确表示时，不强制另加变量。
- 距离、可达性、覆盖半径、预算与公平性条件由原题决定，不从示例强行添加或删除。
- 可行性、最优性、鲁棒性分别检查；不能仅凭求解状态字符串称最优。

缺少必要参数或验证证据时回到对应模块，保持待审或未完成。通用规则见[运行主规范](../../通用/模块化总控与调用规范.md)；题目实测记录保存在对应题包，不写入规范。
